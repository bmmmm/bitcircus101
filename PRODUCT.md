## Platform

web

## Product Purpose

bitcircus101 is an open hackspace in Bonn. Its website provides information and event access. The `/anmeldung/` subpage lets visitors register for “bitcircus101 on rails”, with an arrival animation followed by a form and a separate ticket page.

## Capabilities and Constraints

- Plain HTML, CSS and JavaScript; no framework, bundler or new runtime dependency.
- Preserve the existing system monospace font and dark/light design tokens.
- Event: 23 January 2027, arrival at 11:00, Europe/Berlin. Confirmed by the user.
- Venue: bitcircus 101, Dorotheenstraße 101, Bonn. Confirmed by the user.
- End time, admission conditions and what to bring are not yet confirmed.
- Existing hosting is GitHub Pages. Actual registration requires a server endpoint and email configuration; preview mode must never imply a real registration.
- Local preview and responsive verification are part of the requested delivery.

## Accessibility & Inclusion

Visible labels, keyboard navigation, submission-time validation, touch targets at least 44 pixels, and a static alternative for reduced motion. The decorative train is hidden from assistive technology.
