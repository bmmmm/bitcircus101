~ /pinnwand

pinnwand: hall of working#

Hier hängen Firmen einen Zettel auf: einen Link zu ihrer Stellenanzeige, gegen eine Spende an den Space. Die Anzeige selbst liegt bei der Firma – wir hosten nichts, wir verlinken. Und das Geld hält bei uns das Licht an.

zettel#

zettel aufhängen#

Ein Link auf eure Stellenanzeige, gegen eine Spende an den Space: 1 monat ab 50 €, 3 monate ab 120 €, 12 monate ab 400 €. Richtwerte – mehr ist eine Spende, weniger auch.

so hängt ihr einen Zettel auf
  1. Eintrag anhängen. Hängt dieses Objekt in jobs.json ans postings-Array – eine Anzeige pro Pull Request: 
    {
  "id": "acme-2026-09",
  "company": "ACME GmbH",
  "title": "Embedded-Entwickler:in (m/w/d), Bonn oder remote",
  "url": "https://acme.example/jobs/embedded",
  "from": "2026-09-03",
  "months": 3
}

    jobs.json auf GitHub bearbeiten ↗

    Der Web-Editor legt die Kopie und den Pull Request selbst an, ganz ohne Clone. Kein Git im Haus? Schickt uns den Schnipsel per E-Mail, dann schreiben wir den Pull Request.

  2. Spenden. Verwendungszweck JOBS-<id>, also z. B. JOBS-acme-2026-09. Schreibt Kanal und Datum in die Beschreibung des Pull Requests, dann finden wir die Spende wieder.

    Überweisung

    Klassisch per Bank – IBAN auf Anfrage.

    IBAN anfragen

    PayPal

    Direkt über PayPal.me.

    PayPal öffnen ↗

    Ko‑fi

    Einmalig oder monatlich als Unterstützer:in.

    Ko-fi öffnen ↗
  3. Wir hängen auf. Die CI prüft den Eintrag, wir prüfen die Spende, dann wird gemergt – und der Zettel hängt. Gerechnet wird nach Kalender: ein Monat ab dem 01.09. hängt bis einschließlich 30.09., danach nimmt sich der Zettel selbst wieder ab.
spielregeln
  • Nur https-Links, direkt auf die Anzeige.
  • Eine Anzeige pro Pull Request.
  • Nichts, was nach dem AGG diskriminiert.
  • Wir dürfen einen Zettel ablehnen oder wieder abnehmen.
  • Eine Spende ist eine Spende – keine Rechnung, keine Buchung von Werbefläche.
